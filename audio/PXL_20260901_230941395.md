To add 3-digit numbers quickly in your head, the core strategy is to break the numbers apart and add from left to right (hundreds first), rather than right to left like you do on paper.
This reduces the mental strain of "carrying" numbers.
Here are the best mathematical tricks and mental strategies to speed up your addition:
## 1. The Left-to-Right Strategy (Splitting)
On paper, you start with the ones column. In your head, it is much faster to start with the hundreds, then add the tens, and finally the ones.

* How it works: Split the second number into its place values.
* Example: $342 + 235$
* Start with: $342$
   * Add the hundreds: $342 + \mathbf{200} = 542$
   * Add the tens: $542 + \mathbf{30} = 572$
   * Add the ones: $572 + \mathbf{5} = \mathbf{577}$

## 2. Compensation (Rounding Up)
If one of the numbers ends in a high digit like 7, 8, or 9, round it up to the nearest easy tens or hundreds boundary, add the numbers, and then subtract the difference.

* How it works: Make an easier problem, then adjust at the end.
* Example: $456 + 198$
* $198$ is very close to $200$ (just $2$ short).
   * Round it up: $456 + \mathbf{200} = 656$
   * Subtract the extra $2$: $656 - \mathbf{2} = \mathbf{654}$

## 3. The "Make a Hundred" Rule (Bridging)
Look for opportunities to pull a small amount from one number to bump the other number up to a perfect hundred.

* How it works: Transfer a small value from the harder number to the "almost-rounded" number.
* Example: $295 + 143$
* $295$ needs exactly $5$ to become a clean $300$.
   * Steal $5$ from $143$ (leaving $138$).
   * Rewrite the problem: $\mathbf{300} + 138 = \mathbf{438}$

## 4. Grouping by Columns (Full Separation)
For pairs of numbers where you don't have to carry many digits, you can separate both numbers completely, add each column, and combine them.

* How it works: (Hundreds + Hundreds) + (Tens + Tens) + (Ones + Ones)
* Example: $523 + 364$
* Add Hundreds: $500 + 300 = 800$
   * Add Tens: $20 + 60 = 80$
   * Add Ones: $3 + 4 = 7$
   * Combine: $800 + 80 + 7 = \mathbf{887}$

## 💡 The Golden Rule for Mental Math
Never try to visualize the written addition algorithm in your head. Picturing "carrying the 1" over a column in a mental scratchpad takes too much working memory and causes mistakes. Instead, choose a technique above that lets you speak the running total to yourself as you go.
